# جاهزية الخدمات الذكية: المساعد الصوتي والإشعارات

## ما تم تفعيله داخل Souf 360

يستقبل المساعد الذكي الآن **إملاءً صوتياً اختيارياً**. لا يرسل التطبيق التسجيل الصوتي إلى خادم خاص به؛ بل يحوّل نظام التعرّف في الجهاز الكلام إلى نص، ويعرض النص في حقل السؤال ليتمكن الزائر من مراجعته قبل الضغط على الإرسال. بعد ذلك فقط يستدعي التطبيق نفس وظيفة Supabase الآمنة الخاصة بالمساعد، بما يحافظ على قيد أن الإجابة السياحية تأتي من تدفق التطبيق الموجود ولا تُنشأ من واجهة مستقلة.

## إشعارات الأماكن والفعاليات الجديدة

لن تُدرج مفاتيح Firebase أو ملف خدمة إرسال في APK أو GitHub. التفعيل الإنتاجي يحتاج مشروع Firebase مملوكاً للحساب نفسه، لأن كل تطبيق Android يجب تسجيله بالحزمة الفعلية وتحميل ملف إعداد خاص به. كما أن Android 13 وما بعده يتطلب موافقة المستخدم وقت التشغيل قبل عرض الإشعارات [1] [2].

| المكوّن | التنفيذ المقترح | الضابط الأمني |
| --- | --- | --- |
| تطبيق Souf 360 | تسجيل `com.souf360.app` في مشروع Firebase ثم إضافة `google-services.json` محلياً | الملف لا يحتوي مفتاح خادم، لكنه لا يُرفع عشوائياً إلى مستودع عام. |
| Algeria 360 Beta | تسجيل `com.algeria360.beta` كمُعرّف مستقل | لا يشارك ملف إعداد Souf 360 أو حزمة التوقيع. |
| حفظ اشتراك الجهاز | جدول Supabase لأجهزة اختارت الإشعارات مع رمز FCM مجزّأ وتاريخ تحديث وتفضيلات نوع التنبيه | RLS يمنع قراءة الرموز من التطبيق العام، ويمكّن الجهاز من إدارة رمزه فقط. |
| الإرسال | وظيفة Supabase Edge تستدعي FCM HTTP v1 عند اعتماد مكان أو فعالية من Souf Admin | حساب خدمة Firebase ومفاتيحه في أسرار Edge Function فقط، وليس في APK. |
| الخصوصية | طلب الإذن بعد ضغط المستخدم على زر «تنبيهات الأماكن والفعاليات» | لا يُطلب الإذن عند أول فتح، ولا يستخدم الموقع إلا عند تفعيل تنبيهات قريبة صراحة. |

> لا يمكن إرسال إشعار Push حقيقي أو اختبار وصوله قبل أن يربط مالك المشروع حساب Firebase بالحزمتين؛ إضافة SDK من دون هذا الربط ستنتج تطبيقا يطلب إذناً لكنه لا يملك قناة إرسال موثوقة.

## الإجراء اليدوي الوحيد قبل تفعيل الإشعارات

يُنشئ مالك المشروع مشروع Firebase أو يختار مشروعه الموجود، ويسجّل الحزمتين أعلاه، ثم يوفر ملفي `google-services.json` عبر قناة آمنة. بعد ذلك يُحفظ حساب خدمة FCM في أسرار Supabase، وتُنشأ وظيفة Edge للإرسال من لوحة Souf Admin فقط. لا تستخدم رمز FCM أو حساب الخدمة داخل Flutter أو في متغيرات عامة للموقع.
